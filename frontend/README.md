# 💻 AutoMartX – Frontend Web Application

React + TypeScript + Tailwind CSS web interface for AutoMartX.

## 🚀 Tech Stack
- **Framework**: React 18 + Vite / Next.js
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **State & Query**: TanStack Query / Redux Toolkit
- **Icons**: Lucide React / Heroicons

## 📁 Directory Structure
```text
frontend/
├── src/
│   ├── assets/        # Media & logos
│   ├── components/    # Reusable UI components
│   ├── pages/         # Marketplace pages (Home, Listings, VehicleDetail, Sell)
│   ├── services/      # API client services
│   └── types/         # TypeScript interfaces
├── public/            # Static assets
├── package.json
└── README.md
```

## 🛠️ Local Setup
```bash
npm install
npm run dev
```
